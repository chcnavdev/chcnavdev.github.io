# 激光测量

本节旨在帮助开发者快速集成并使用激光测量功能。激光测量相关类位于 **`gnssserver`** 模块包名 **`com.huace.gnssserver.sdk.laser`**（`LaserDeviceManager`、`LaserPositionListener`、`LaserPosition`、`EnumLaserStatus`），集成方需依赖包含该 SDK 的制品。通过上述 API 可实现激光测距与位置信息的实时获取；`LaserPositionListener` 同时提供 **相机打开过程状态**（`RtkCameraStatus`）与 **视频错误** 回调。文档将重点介绍如何配置、初始化以及使用相关 API，同时也会涉及到数据模型和状态码的说明。

## 前置条件

在使用激光测量功能前，请确保满足以下条件：

1. **与接收机通信正常** — 激光数据依赖与接收机的连接；请按业务约定保证链路可用（如需可调用工程内已有的 WiFi / 数据链状态接口做前置校验；演示页 `LaserDeviceActivity` 当前仅校验是否支持激光）。
2. **接收机支持激光测量** — 确认当前连接的接收机硬件支持激光测量功能。可通过 `ReceiverUtils.isSupportLaser()` 进行检查，若不支持则 `openLaser()` 会返回 `false`。
3. **接收机已固定并有位置输出** — 激光测距结果依赖接收机解算出的位姿等信息；不固定的情况下会出现无数据、数据不稳定或精度不满足预期等情况。

```java
if (!ReceiverUtils.isSupportLaser()) {
    // 提示用户当前接收机不支持激光测量
    return;
}
```

## 初始化激光功能

`LaserDeviceManager` 以单例模式提供，无需额外创建实例。初始化流程如下：

1. 通过 `LaserDeviceManager.getInstance()` 获取全局唯一实例；
2. 注册 `LaserPositionListener` 监听器，接收激光位置数据、视频错误以及相机打开过程状态；
3. 调用 `openLaser()` 启动激光测量；
4. 建议先调用 `ReceiverUtils.isSupportLaser()`（以及业务所需的链路 / 连接方式检查）再启动。

### 预览路与计算路

当前实现 **固定为双路顺序打开**：先打开 **预览路**（`FRONT_PREVIEW_LASER_CAMERA`），在预览路 **`onDataReceived` 收到首帧** 后再打开 **高清计算路**（`FRONT_HIGH_QUALITY_LASER_CAMERA`），避免仅在 `onStatusChanged` 中判断就绪带来的时序问题。

- **`onLaserPositionChanged` / `getLatestLaserPosition()` 的数据始终来自高清计算路** 的 `onDataReceived`；预览路不向外投递测距结果。
- **`onLaserVideoError`**：预览路或计算路在 `onError` 时均会回调，**不区分底层链路**，仅携带错误码。
- **`onLaserOpenStatusChanged`**（与 `LaserPositionListener` / `LaserDeviceManager` 约定一致，实际转发规则如下）：
    - 在 `openLaser()` 成功提交打开流程后，会 **派发一次** `RtkCameraStatus.OPENING`（表示已提交启动流程）；
    - **预览路** `onStatusChanged`：除 **`OPENED`** 外，其余状态会原样转发给监听器（预览路自身进入 `OPENED` 时 **不** 通过本回调透出）；
    - **计算路** `onStatusChanged`：仅在状态为 **`OPENED`** 时转发；计算路在打开过程中的其它状态（如 `OPENING`、`OPEN_FAILED` 等）**不会**通过本方法从计算路侧透出。接口语义上 **`OPENED` 表示预览路已能出图且高清计算路已打开**（计算路仅在预览路 **首帧 `onDataReceived`** 之后才会启动，故收到 `OPENED` 时可认为两路就绪）；
    - 若计算路异常，请关注 `onLaserVideoError` 及业务层超时/重试策略。

```java
import com.huace.gnssserver.sdk.laser.LaserDeviceManager;
import com.huace.gnssserver.sdk.laser.LaserPosition;
import com.huace.gnssserver.sdk.laser.LaserPositionListener;
import com.huace.gnssserver.sdk.receiver.ReceiverUtils;
import com.huace.gnssserver.sdk.receiver.camera.RtkCameraStatus;

private void initLaser() {
    // 1. 检查设备是否支持激光测量
    if (!ReceiverUtils.isSupportLaser()) {
        // 设备不支持激光功能，提示用户
        return;
    }

    // 2. 创建监听器（接口三个方法均需实现）
    LaserPositionListener listener = new LaserPositionListener() {
        @Override
        public void onLaserPositionChanged(@NonNull LaserPosition position) {
            // 激光位置数据更新时的回调（来自高清计算路）
            // 注意：回调线程与底层数据投递线程一致，如需更新 UI 应自行切换到主线程
            runOnUiThread(() -> updateUI(position));
        }

        @Override
        public void onLaserVideoError(int errorCode) {
            // 预览路或计算路视频错误均会回调，不区分底层链路
            Log.w(TAG, "Laser video error code=" + errorCode);
        }

        @Override
        public void onLaserOpenStatusChanged(@NonNull RtkCameraStatus status) {
            // 整体打开过程状态（见上文「预览路与计算路」）
            Log.d(TAG, "Laser open status: " + status);
        }
    };

    // 3. 注册监听器并启动（同一 listener 实例重复 addListener 会被忽略）
    LaserDeviceManager.getInstance().addListener(listener);
    LaserDeviceManager.getInstance().openLaser();
}
```

## 激光操作

`LaserDeviceManager` 提供以下核心操作方法：

### 启动 / 停止激光测量

```java
// 启动激光测量
findViewById(R.id.btnStartLaser).setOnClickListener(v -> {
    if (!ReceiverUtils.isSupportLaser()) {
        Toast.makeText(this, "设备不支持激光测量", Toast.LENGTH_SHORT).show();
        return;
    }
    LaserDeviceManager.getInstance().addListener(mListener);
    LaserDeviceManager.getInstance().openLaser();
});

// 停止激光测量
findViewById(R.id.btnStopLaser).setOnClickListener(v -> {
    LaserDeviceManager.getInstance().removeListener(mListener);
    LaserDeviceManager.getInstance().closeLaser();
});
```

### 拉取最新激光数据

```java
findViewById(R.id.btnGetLatest).setOnClickListener(v -> {
    LaserPosition position = LaserDeviceManager.getInstance().getLatestLaserPosition();
    if (position == null) {
        Log.d(TAG, "暂无激光数据");
    } else {
        Log.d(TAG, "最新激光数据: " + position.toString());
    }
});
```

## 数据模型

`LaserPosition` 类封装了完整的激光测量数据，主要字段说明如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| `timestampMs` | `long` | 本地时间戳（毫秒） |
| `laserDistance` | `double` | 激光测量距离 |
| `laserLat` | `double` | 激光点纬度 |
| `laserLon` | `double` | 激光点经度 |
| `laserHgt` | `double` | 激光点高程 |
| `laserHardAccuracy` | `double` | 激光测量精度（硬精度；小于 1.0 时通常可认为可用，具体阈值可按业务调整） |
| `laserAcc` | `double` | 精度因子；**建议小于 0.6 时可认为精度可用**（经验阈值，可按产品要求调整） |
| `laserScaling` | `double` | 缩放比例 |
| `laserXPre` | `int` | 激光 X 方向误差 |
| `laserYPre` | `int` | 激光 Y 方向误差 |
| `laserZPre` | `int` | 激光 Z 方向误差 |
| `laserXInImagePx` | `double` | 激光点在图像中的横坐标（像素） |
| `laserYInImagePx` | `double` | 激光点在图像中的纵坐标（像素） |
| `laserStatus` | `EnumLaserStatus` | 激光测量设备状态 |
| `laserError` | `int` | 激光测量原始故障码 |

## RtkCameraStatus 说明

`RtkCameraStatus` 定义于 `com.huace.gnssserver.sdk.receiver.camera`，表示 **RTK 相机设备** 在打开流程中的状态。集成方在 `LaserPositionListener#onLaserOpenStatusChanged` 中收到的值，来源为 **管理器注入的一次 `OPENING`** 以及 **预览路 / 计算路按上文「预览路与计算路」规则转发的底层状态**（并非单一相机实例的完整状态流）。各枚举含义与底层一致。

| 枚举值 | 说明 |
|--------|------|
| `UN_OPENED` | 设备未打开 |
| `UN_SUPPORT` | 设备不支持 |
| `UN_CONNECTED` | 未与 RTK 建立连接 |
| `CONNECTION_WAY_NOT_SUPPORT` | 当前连接方式不支持 |
| `PARAMETER_GET_FAILED` | 相机参数获取失败 |
| `OPENING` | 相机正在打开 |
| `OPEN_FAILED` | 相机打开失败 |
| `DEVICE_IS_OCCUPIED` | 相机被占用（常见于已有其他手簿连接该接收机） |
| `OPENED` | 已经打开 |

SDK 还提供 `isOpeningOrOpened()`，当状态为 `OPENING` 或 `OPENED` 时返回 `true`，便于判断「已在打开过程中或已打开」。

## 状态码说明

`EnumLaserStatus` 枚举定义激光测量设备的各状态；枚举 **码值** 与 LandStar8 侧同名枚举保持一致（包名不同），未匹配的原始码会映射为 `OTHER_UNKNOWN`。

| 枚举值 | 码值 | 说明 |
|--------|------|------|
| `NORMAL` | `0` | 正常 |
| `DATA_ABNORMAL` | `1000` | 数据异常 |
| `SIGNAL_WEAK` | `1001` | 信号弱 |
| `OVER_RANGE` | `1002` | 超量程 |
| `SIGNAL_TOO_STRONG` | `1003` | 信号过强 |
| `LD_ERROR` | `1004` | 激光二极管故障 |
| `BACKGROUND_LIGHT_STRONG` | `1005` | 背景光过强 |
| `HARDWARE_ERROR` | `1006` | 硬件错误 |
| `LIGHT_LEAKAGE` | `1007` | 漏光 |
| `REFLECTIVITY_ABNORMAL` | `1008` | 反射率异常 |
| `TEMPERATURE_ABNORMAL` | `1009` | 温度异常 |
| `OTHER_UNKNOWN` | `1100` | 其他未知错误 |

调用方可通过 `position.getLaserStatus()` 获得当前设备状态，结合 `getLaserStatus().getCode()` 获取原始码值；也可直接通过 `position.getLaserError()` 获取原始故障码。

## 生命周期管理

`LaserDeviceManager` 内部管理预览路与高清计算路的资源，使用方需在合适的生命周期节点释放资源：

```java
@Override
protected void onDestroy() {
    super.onDestroy();
    LaserDeviceManager.getInstance().removeListener(mListener);
    LaserDeviceManager.getInstance().closeLaser();
}
```

## 完整代码

工程内演示页为 `com.huace.gnsstest.laser.LaserDeviceActivity`（含不支持激光时的 `AlertDialog` 提示与 `strings.xml` 文案）。下面给出与演示页一致的核心逻辑摘录，便于对照或复制到自有模块。

```java
import android.app.AlertDialog;
import android.os.Bundle;
import android.widget.TextView;

import androidx.annotation.NonNull;
import androidx.annotation.Nullable;
import androidx.appcompat.app.AppCompatActivity;

import com.huace.gnssserver.sdk.laser.LaserDeviceManager;
import com.huace.gnssserver.sdk.laser.LaserPosition;
import com.huace.gnssserver.sdk.laser.LaserPositionListener;
import com.huace.gnssserver.sdk.receiver.ReceiverUtils;
import com.huace.gnssserver.sdk.receiver.camera.RtkCameraStatus;
import com.huace.gnsstest.R;

public class LaserDeviceActivity extends AppCompatActivity {

    private final LaserPositionListener mListener = new LaserPositionListener() {
        @Override
        public void onLaserPositionChanged(@NonNull LaserPosition position) {
            renderPosition(position);
        }

        @Override
        public void onLaserVideoError(int errorCode) {
            renderText(getString(R.string.laser_error_video, errorCode));
        }

        @Override
        public void onLaserOpenStatusChanged(@NonNull RtkCameraStatus status) {
            renderText(status.name());
        }
    };

    private TextView mTvLaser;

    @Override
    protected void onCreate(@Nullable Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_laser_survey);
        mTvLaser = findViewById(R.id.tvLaser);
        findViewById(R.id.btnStartLaser).setOnClickListener(v -> {
            if (!ReceiverUtils.isSupportLaser()) {
                new AlertDialog.Builder(this)
                        .setTitle(getString(R.string.laser_dialog_title))
                        .setMessage(getString(R.string.laser_not_supported))
                        .setPositiveButton(getString(R.string.laser_dialog_ok), null)
                        .show();
                return;
            }
            LaserDeviceManager.getInstance().addListener(mListener);
            LaserDeviceManager.getInstance().openLaser();
        });
        findViewById(R.id.btnStopLaser).setOnClickListener(v -> {
            LaserDeviceManager.getInstance().removeListener(mListener);
            LaserDeviceManager.getInstance().closeLaser();
            renderText(getString(R.string.laser_stopped));
        });
        findViewById(R.id.btnGetLatest).setOnClickListener(v -> {
            LaserPosition position = LaserDeviceManager.getInstance().getLatestLaserPosition();
            if (position == null) {
                renderText(getString(R.string.laser_latest_null));
            } else {
                renderPosition(position);
            }
        });
    }

    @Override
    protected void onDestroy() {
        LaserDeviceManager.getInstance().removeListener(mListener);
        LaserDeviceManager.getInstance().closeLaser();
        super.onDestroy();
    }

    private void renderPosition(@NonNull LaserPosition position) {
        String text = "timestampMs=" + position.getTimestampMs()
                + "\ndistance=" + position.getLaserDistance()
                + "\nlat=" + position.getLaserLat()
                + "\nlon=" + position.getLaserLon()
                + "\nh=" + position.getLaserHgt()
                + "\nhardAccuracy=" + position.getLaserHardAccuracy()
                + "\nacc=" + position.getLaserAcc()
                + "\nscaling=" + position.getLaserScaling()
                + "\nxPre=" + position.getLaserXPre()
                + "\nyPre=" + position.getLaserYPre()
                + "\nzPre=" + position.getLaserZPre()
                + "\nerror=" + position.getLaserError()
                + "\nlaserXInImagePx=" + position.getLaserXInImagePx()
                + "\nlaserYInImagePx=" + position.getLaserYInImagePx()
                + "\nstatus=" + position.getLaserStatus().name()
                + "(" + position.getLaserStatus().getCode() + ")";
        renderText(text);
    }

    private void renderText(@NonNull String text) {
        runOnUiThread(() -> mTvLaser.setText(text));
    }
}
```

## API 参考

### LaserDeviceManager

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `getInstance()` | `LaserDeviceManager` | 获取单例实例 |
| `openLaser()` | `boolean` | 启动激光测量：当前接收机不支持激光时返回 `false`；**已在运行中时返回 `true`（幂等）**；首次成功提交打开流程时返回 `true` |
| `closeLaser()` | `void` | 停止激光测量，关闭已打开的摄像头并清空缓存的最新位置；未启动时调用无副作用 |
| `getLatestLaserPosition()` | `@Nullable LaserPosition` | 获取最近一次激光位置数据（来自高清计算路）；尚无数据或已停止时为 `null` |
| `addListener(LaserPositionListener)` | `void` | 注册监听器；**同一实例不会重复加入** |
| `removeListener(LaserPositionListener)` | `void` | 注销监听器 |

### LaserPositionListener

| 方法 | 说明 |
|------|------|
| `onLaserPositionChanged(LaserPosition)` | 激光位置数据更新时回调，数据来自高清计算路 |
| `onLaserVideoError(int errorCode)` | 预览路或计算路视频相关错误，**不区分底层链路**，仅携带错误码 |
| `onLaserOpenStatusChanged(RtkCameraStatus status)` | 整体打开过程状态（见上文 **「预览路与计算路」**）；各枚举含义见 **「RtkCameraStatus 说明」** |

> **注意**：`onLaserPositionChanged`、`onLaserVideoError`、`onLaserOpenStatusChanged` 的回调线程均与底层相机/数据投递线程一致，调用方如需更新 UI 应自行切换到主线程。
